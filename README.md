# NIVAS Rentals

NIVAS rental-house mobile app source.

## Build
1. Install Node.js.
2. Run `npm install`.
3. Run `npx expo start`.
4. For an Android release, configure an Expo/EAS Android build and replace the temporary owner payment screen with a real verified payment gateway before production.

## Important
The ₹99 screen included here is intentionally a payment-flow placeholder, not a real payment processor. Do not claim real payments are connected until gateway credentials, server-side verification, webhook handling, and Play Store production configuration are completed.
